# 브랜드 컬러 (HYROX 공식 사이트 기준)

[HYROX Korea](https://hyroxsouthkorea.com/ko/) 및 [hyrox.com](https://hyrox.com/) 테마에서 추출한 값입니다.  
하이록스 맵은 **비공식** 서비스이며 HYROX 본사와 무관합니다.

| 용도 | CSS 변수 | Hex |
|------|----------|-----|
| 포인트 (CTA, 활성 탭, 뱃지) | `--hyrox-yellow` | `#FFED00` |
| 포인트 hover | `--hyrox-yellow-hover` | `#E6D500` |
| 텍스트 on yellow | `--hyrox-black` | `#000000` |
| 지도 패널 배경 | `--hyrox-panel` | `#262626` |

Tailwind: `bg-hyrox-yellow`, `text-hyrox-black`, `bg-hyrox-panel`, `map-panel-surface`
